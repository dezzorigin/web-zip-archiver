Web ZIP Archiver — arsitektur & alur

Static export Next.js di Cloudflare Pages + satu Pages Worker (worker/_worker.js) sebagai server API. Worker mem-proxy dua rute ke copier.saveweb2zip.com (layanan saveweb2zip.com yang melakukan crawling + zipping). File ZIP hasil akhirnya diunduh langsung dari server upstream, bukan dari Pages.

Kenapa worker, bukan API route Next.js? Build static export (output: 'export') menolak route handler dinamis apa pun — repo versi lama gagal build karena app/api/clone/* (force-dynamic tidak bisa dipakai dengan static export). Logika rute dipindah apa adanya ke worker/_worker.js, yang di-deploy bersama out/ sebagai _worker.bundle. Lihat docs/ARCHITECTURE.md untuk detail dan docs/API.md untuk kontrak tiap rute.
